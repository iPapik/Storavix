# Locate / Stop Locate — идентификация диска

На Windows-хосте с агентом v0.2.25+ и установленным поддерживаемым StorCLI/PercCLI (включая варианты CLI2, если они принимают команды) откройте карточку сервера → RAID и физические диски → нужный массив либо «Все физические диски». В строке диска выберите Locate и подтвердите имя сервера, адрес и серийный номер. После ответа контроллера проверьте индикатор на корпусе, сопоставьте физический слот и серийный номер. Stop Locate выключает индикацию того же диска. Убедитесь, что на корпусе не мигают другие диски. Не извлекайте диск исключительно по сообщению веб-интерфейса. При уже запущенном rebuild не извлекайте другие диски без оценки отказоустойчивости и резервной копии.

Поддержка зависит от контроллера, прошивки и backplane. Если серийный номер не читается, адрес неоднозначен, данные устарели либо CLI занят, операция отклоняется. При смене диска старый серийный номер не пройдёт повторную проверку. При ошибке CLI или потере ответа проверяйте LED физически. Индикатор не выключается автоматически, статус команды не хранится после перезапуска сервера, а неполученные команды истекают через минуту. Команда доступна только администратору; результат подтверждает ответ CLI, но не физическую исправность LED. Агент использует только фиксированные команды start/stop locate, без shell и без передачи путей к исполняемым файлам с сервера. Для связи агента с сервером используйте HTTPS или изолированную доверенную сеть: существующая схема регистрации использует общий токен.

Linux-агент работает без root, поэтому Locate в этой версии не включён на Linux; HPE SSA, Storage Spaces, Linux MD и неизвестные контроллеры также не поддерживаются. Для Windows Server 2012/R2 используется штатная legacy-сборка внутри MSI/EXE.

Документация: [Broadcom](https://www.broadcom.com/support/knowledgebase/1211161499760/lsi-command-line-interface-cross-reference-megacli-vs-twcli-vs-s), [Dell](https://www.dell.com/support/kbdoc/en-us/000394815/poweredge-managing-the-poweredge-raid-controller-with-perccli).
