# Storavix v0.2.18 — карточки обзора и проверка SMTP

- Карточки «Серверы онлайн», «Коммутаторы» и «Активные алармы» открывают соответствующие разделы.
- Форма SMTP очищена от поясняющих блоков. Порт задаётся в отдельном поле.
- Storavix получает сертификат SMTP по STARTTLS или SSL/TLS и показывает издателя, срок действия и SHA‑256. Для частного сертификата после сверки можно сохранить точный отпечаток. При отправке Storavix проверяет совпадение, имя сервера и срок действия сертификата.
- Кнопки тестирования используют текущие значения формы без сохранения настроек.

Для установки обновите центральный сервер Storavix командой `sudo storavix-update`.
