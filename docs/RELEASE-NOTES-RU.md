# Storavix v0.2.26 — состояния дисков и прогресс Rebuild

- Полные названия состояний физических дисков: Online, Rebuild, Offline, Unconfigured Good/Bad, Global/Dedicated Hot Spare, Missing и другие. Предупреждение о деградации и ошибки дисков сохранены.
- Для диска в Rebuild отображаются состояние операции, процент с полосой прогресса и оставшееся время, если StorCLI/PercCLI сообщает Estimated Time Left. При отсутствии данных показывается соответствующее сообщение, без вымышленных процентов и сроков.
- Убраны подпись под кнопками Locate до выполнения команды, строка «Состояние сбора», пояснения на странице серверов, повторный заголовок и описание сетевого раздела, плашки источников опроса RAID. Кнопки Locate, результаты операций, предупреждения RAID и остальные диагностические показатели сохранены.
- Совместимость с предыдущими серверами и агентами, SMTP/Telegram и Windows Server 2012 R2 сохранены в механизме обновления.

Обновление центрального сервера: `sudo storavix-update`. Для новых параметров восстановления требуется агент v0.2.26; Windows — MSI/EXE из релиза. Контроллер и прошивка определяют доступность ETA; данные обновляются при опросе RAID, а не каждую секунду.
