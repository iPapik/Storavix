# Storavix v0.2.24 — Telegram-уведомления

- Новая вкладка **Настройки → Telegram**: включение канала, Bot Token, Chat ID, необязательный ID темы, поиск доступных чатов и тестовое сообщение.
- Поддержка личных чатов, групп, каналов и тем. Все 17 существующих типов автоматических оповещений доступны для независимого выбора.
- SMTP и Telegram работают через независимые сохраняемые очереди; в журнале отображаются отдельные статусы и ошибки. При ограничении API (HTTP 429) соблюдается пауза перед повторной отправкой. Неоднозначные сетевые ошибки автоматически не повторяются во избежание дубликатов.
- Токен зашифрован на диске, не возвращается клиенту и не включается в сообщения об ошибках; настройки доступны только администратору.
- Telegram выключен по умолчанию; текущая конфигурация SMTP, данные мониторинга и логика v0.2.23 сохранены. Пороги температуры общие для обоих каналов. Настраивается один чат/тема.
- Для работы требуется исходящий HTTPS TCP 443 к api.telegram.org. Входящие порты не нужны.

## Обновление

На центральном Linux-сервере: `sudo storavix-update`. Далее откройте **Настройки → Telegram**, создайте бота через @BotFather, укажите токен и получателя, отправьте тестовое сообщение, выберите события и сохраните.

Агенты специально для Telegram обновлять не нужно. MSI и EXE собираются в рамках стандартного релиза, включая поддержку Windows Server 2012/R2. В этой версии код сбора телеметрии агента не менялся, только номер версии.

[Руководство по Telegram](https://github.com/iPapik/Storavix/blob/v0.2.24/docs/TELEGRAM-RU.md). Используйте HTTPS для административной панели или доверенную изолированную сеть. Для реальной доставки требуется проверить собственный бот.
