# Storavix v0.2.16 — обновление Windows-агента и опрос Storage Spaces

- MSI и EXE подхватывают сохранённые URL и токен и запускают агент после обновления. Настроенный агент можно обновлять интерактивно или в тихом режиме.
- Запись настроек совместима с PowerShell 4.0 на Windows Server 2012 R2.
- Опрос Storage Spaces различает отсутствие пулов, отсутствие модуля и ошибку опроса. Состояние аппаратных RAID по-прежнему определяется данными утилиты контроллера.
- В таблице физических дисков убрана колонка «Роль». Значок кнопки «Обновить» выровнен относительно текста.

Обновите центральный сервер командой `sudo storavix-update`. Для исправления опроса Storage Spaces обновите также Windows-агенты.
