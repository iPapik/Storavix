# Storavix v0.2.15 — обнаружение аппаратных RAID-контроллеров

- Агенты Windows и Linux показывают обнаруженные ОС RAID-контроллеры, даже когда утилита производителя недоступна. Массивы и диски отображаются по данным поддерживаемого RAID CLI.
- Агент может установить подготовленную копию StorCLI, StorCLI2, PercCLI, PercCLI2 или HPE SSA CLI из локального файла, UNC-пути на Windows или HTTPS. Перед заменой проверяются SHA‑256 и архитектура исполняемого файла.
- Онлайн-установка и обновление подхватывают настроенный источник RAID CLI и выполняют установку на серверах с подходящим оборудованием.
- Для штатного сбора Linux MD и Windows Storage Spaces по-прежнему достаточно средств операционной системы.

Для получения новых данных обновите агенты. Центральный сервер v0.2.15 показывает этот источник понятной подписью. [Установка и развёртывание](https://github.com/iPapik/Storavix/blob/main/docs/AGENT-RU.md).
