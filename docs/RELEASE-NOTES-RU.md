# Storavix v0.2.19 — автоматические уведомления SMTP

- В настройках SMTP можно выбрать события для почтовой отправки. Журнал записывает переходы состояний и показывает время обнаружения и статус отправки.
- Добавлены события доступности серверов и коммутаторов, перегрева и охлаждения, заполнения системного тома, начала и завершения восстановления RAID, деградации и отказа RAID, предупреждений и отказов физических дисков.
- Температуру сервера передаёт обновлённый агент при наличии доступного датчика. Для коммутаторов Storavix использует ENTITY-SENSOR-MIB либо указанный в настройках коммутатора OID. Пороги по умолчанию 80 °C для серверов и 70 °C для коммутаторов.

Обновите центральный сервер командой `sudo storavix-update`. Для мониторинга температуры серверов обновите агенты. Чтобы включить автоматическую отправку, сохраните нужные галочки в «Настройки» → «SMTP».
