# Storavix v0.2.13 — автосортировка виджетов и пользователи

- Обзор автоматически заполняет свободные места в сетке, учитывая порядок и размеры виджетов. В режиме «Настроить обзор» автосортировку можно выключить для точного размещения.
- Флажок «Принимать события Syslog» находится в заголовке настроек приёмника. Опции UDP/TCP расположены рядом со своими подписями.
- В «Настройки → Пользователи» администраторы могут создавать учётные записи, менять права и пароли, удалять пользователей. Существующий владелец сохраняет учётные данные и права.
- Наблюдатель просматривает доступные разделы. Оператор дополнительно может менять настройки доступных коммутаторов, запускать их опрос и задавать местоположения устройств. Оператор с доступом ко всем разделам также может менять общий обзор и сетевые схемы. Администратор имеет полный доступ, включая пользователей, SMTP и Syslog.
- Область доступа выбирается отдельно: «Только серверы», «Серверы и коммутаторы» или «Все разделы». В ограниченных областях обзор, геокарта и активные алармы содержат сведения только о доступном оборудовании. Изменение прав или пароля завершает сеансы этой учётной записи.

Обновите центральный сервер командой `sudo storavix-update`. Обновлять агенты для этих изменений не требуется.
