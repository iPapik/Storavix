# Storavix v0.2.12 — Syslog, геокарта и сетка виджетов

- Настройки SMTP, Syslog и безопасности собраны в разделе «Настройки». Вкладка Syslog управляет IP, портом, UDP/TCP и числом сохраняемых сообщений. На новой установке приём выключен, предложенный порт — 5514.
- Журнал Syslog принимает сообщения RFC 3164 и RFC 5424. Для TCP поддерживается разделение по строкам и по длине RFC 6587. Сообщения сохраняются на сервере между перезапусками. Журнал можно фильтровать по источнику, уровню и тексту.
- «Карты → Геокарта» показывает серверы и коммутаторы на OpenStreetMap. Для каждого устройства можно сохранить координаты, выбрать точку на карте или найти адрес через Photon. Поиск передаёт введённый адрес внешнему сервису. Чтобы использовать свой Photon, задайте `STORAVIX_GEOCODER_URL` в окружении сервера.
- «Обзор → Настроить обзор» позволяет перемещать виджеты за верхнюю ручку и менять высоту и ширину за нижний правый угол. Для ручек также работают клавиши со стрелками. Геокарта доступна в списке виджетов. Существующая раскладка переносится в сетку.
- В верхней строке обзора отображается число коммутаторов. Увеличены шрифты панели.

Обновите центральный сервер командой `sudo storavix-update`. Для этих функций обновление агентов не требуется. После включения Syslog разрешите вход на выбранный порт от нужных источников. При установке через Docker опубликуйте порт приёмника для выбранных протоколов, например `5514:5514/udp`.
