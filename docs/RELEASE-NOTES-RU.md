# Storavix v0.2.17 — состояние дисков, название ОС и Dell PERCcli

- Заголовок RAID показывает предупреждение или отказ входящего в него диска. В деталях виден исходный статус массива по данным контроллера.
- Состояния сервера выделены цветом. Онлайн отображается зелёным, предупреждение жёлтым, критическое состояние красным.
- Агент присылает полное название ОС. Windows определяется по подписи системы, Linux по `os-release`.
- Windows-агент находит PERCcli в системном каталоге и умеет извлекать `perccli64.exe` из проверенного пакета Dell ZPE. Для старых версий PERCcli предусмотрен опрос контроллеров по отдельности.
