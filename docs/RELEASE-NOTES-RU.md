# Storavix v0.2.25 — Locate физических дисков RAID

- В карточке RAID добавлена колонка «Идентификация» с кнопками Locate и Stop Locate для Windows-агентов с StorCLI/PercCLI.
- Перед выполнением агент повторно проверяет адрес диска и серийный номер, а при наличии — серийный номер контроллера. Команда отклоняется при устаревших данных, неподдерживаемом контроллере, несовпадении SN или отсутствии подтверждения CLI.
- Запуск доступен только администратору. Отправка команд не блокирует основной heartbeat. Используются только команды индикации; состояние RAID не меняется.
- Веб-интерфейс показывает очередь, выполнение и результат CLI. После запуска необходимо физически проверить индикатор, слот и SN; автоматического выключения нет.
- Linux, HPE SSA, Storage Spaces, Linux MD и диски без точного адреса/SN в этой версии не поддерживаются. Фактическая индикация зависит от контроллера и backplane.
- Telegram и SMTP из предыдущей версии сохранены.

## Обновление
1. Центральный сервер: `sudo storavix-update`.
2. Обновить Windows-агент через MSI или Setup EXE из этого релиза, сохранив существующую регистрацию.
3. Открыть карточку RAID после поступления свежей телеметрии. Проверить Locate на известном диске без его извлечения, затем Stop Locate.

[Подробная инструкция](https://github.com/iPapik/Storavix/blob/main/docs/LOCATE-RU.md).
