# Оповещения Telegram

1. Создайте отдельного бота через [@BotFather](https://t.me/BotFather), команда /newbot. Сохраните токен как пароль.
2. Для личного чата откройте бота и нажмите Start. Для группы добавьте бота и отправьте /start@имя_бота; для канала назначьте его администратором с правом публикации.
3. В Storavix откройте Настройки → Telegram, введите Bot Token и нажмите «Найти чаты». Выберите нужный Chat ID либо введите его вручную (для публичного канала можно использовать @username). Поиск видит только недавние доступные обновления; используйте отдельного бота без webhook. При необходимости укажите числовой ID темы форума.
4. Нажмите «Отправить тестовое сообщение». Убедитесь, что сообщение пришло именно в нужный чат.
5. Включите отправку, выберите события и сохраните настройки. SMTP настраивается независимо. Пороги температуры общие для двух каналов.

Для работы нужен исходящий HTTPS TCP 443 к api.telegram.org и рабочий DNS. Входящие порты, webhook и обновление агентов не требуются. При вводе токена в веб-интерфейсе используйте HTTPS либо доверенную изолированную административную сеть. Не передавайте токен через URL браузера, логи или переписку. На сервере токен зашифрован тем же локальным ключом, что и секрет SMTP; резервируйте данные и ключ вместе.

Очереди SMTP и Telegram независимы и сохраняются на диск. Telegram поддерживает один настроенный чат/тему. В журнале отображаются отдельные статусы. При HTTP 429 очередь откладывает повторную попытку; при неоднозначном сетевом отказе автоматической повторной отправки нет, чтобы не создавать дубликаты. При перезапуске неподтверждённые отправки помечаются как неизвестные. При смене получателя или токена ожидающие сообщения отменяются. Для Telegram очередь ограничена 500 сообщениями; история — 1000 событий. Настройки по умолчанию выключены.

Проверка: [Telegram Bot API](https://core.telegram.org/bots/api), [интеграция Zabbix](https://www.zabbix.com/integrations/telegram).
