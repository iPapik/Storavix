Email alerts
Поддерживаются SMTP Relay (без авторизации), STARTTLS, SMTPS, PLAIN, LOGIN, CRAM-MD5 и OAuth2 (XOAUTH2 с готовым токеном). Самоподписанные сертификаты можно доверить через файл CA на сервере.

Секрет SMTP шифруется AES-GCM перед записью на диск. Проверьте SMTP-соединение только после сохранения настроек. Для Microsoft 365 и Google Workspace OAuth2-токен должен быть получен отдельно и обновляться вручную в этой версии.
